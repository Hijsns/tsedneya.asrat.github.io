Backend · May 2026

StudyGuido — BITS @ VT

A study platform built by a cross-functional team through Virginia Tech's BITS program. The app uses the Feynman Technique to help students actually learn, not just read. I worked on the backend and owned the flashcard generation system.

The first version worked but was wasteful: every request regenerated cards from scratch and threw them away. I fixed that by saving cards to a master_flashcard table tied to the user, textbook, and chapter. Now we check the database first and only call Gemini if we still need more cards. I also added a spaced repetition layer using two timestamps (created_at and last_seen) so the app shows cards the user hasn't seen in 24+ hours first. A cron job running every 7 days clears old cards automatically.

Level-Shifting Op-Amp Circuit

Designed a level-shifting amplifier for a simulated ECG signal, taking a ±1V sine wave and shifting it to 0 to 3V for microcontroller input. Calculated the input resistors, closed-loop gain (1.654x), and feedback resistors by hand, then verified everything in LTspice and on a physical breadboard using an LF356 op-amp.

Hit a debugging issue where the AD3 oscilloscope showed a clean waveform but was reading from the wrong input wire, so it wasn't actually capturing the signal I thought it was. Tracing that down taught me to verify the signal path, not just trust what's on screen.

Arduino Enclosure + LED System

Built a portable enclosure for my Arduino so I could bring a live circuit to office hours without taking everything apart. Laser-cut the plywood shell, added USB cutouts so the board stays powered inside, and designed a custom 3D-printed mount in Onshape using an accurate Arduino Uno model.

My original plan was to drill through the plywood for standoffs but the material was too thin to hold it. Pivoted to the printed mount instead, which actually worked better. Also wired and programmed LED sequences using GPIO and PWM.
